# nk-claude-themes: 81 Claude Code terminal themes

**Browse all themes with previews, filters and one-line installs: https://nilaykabariya.blog/claude-code-themes**

Free colour themes for the Claude Code terminal CLI. A theme changes colours only. Unofficial, not affiliated with Anthropic.

## Install the whole set

```bash
claude plugin marketplace add nils44344/nk-repro
claude plugin install nk-claude-themes@nk-themes
```

Inside Claude Code: `/plugin marketplace add nils44344/nk-repro` then `/plugin install nk-claude-themes@nk-themes`. Then run `/theme` and pick one. Plugin themes are read-only.
